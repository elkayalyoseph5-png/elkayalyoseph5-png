# Yoseph Elkayal

I'm an Industrial & Systems Engineering student at Rutgers University (B.S. expected May 2028). I work on embedded systems, sensor data pipelines, and edge AI.

## Selected engineering projects

- **Gas-sensor classification on NVIDIA Jetson.** At the Institute of Physics of the Czech Academy of Sciences (FZU), I built a pipeline from Arduino sensor readout and Python data processing to real-time inference on a Jetson Orin Nano Super. I benchmarked a multilayer perceptron against a random forest and deployed the final model with TensorRT FP16. The classifier reached 80.9% cross-validated accuracy on unseen trials across five gas and vapor states.
- **Custom electric bicycle.** I assembled and tested an e-bike system that integrated a motor controller, battery, safety circuitry, and mechanical mounts.
- **Electronics repair and test automation.** I diagnose and repair electronics at the board and component level and build scripts for hardware testing and routine tasks.

## Tools and skills

- **Programming and data:** Python, C++, MATLAB, serial data logging, time-series analysis
- **Embedded and edge AI:** Arduino, NVIDIA Jetson, I²C and analog sensors, TensorRT
- **Hardware:** Electrical diagnostics, soldering, system integration, and validation testing
